Before you begin · ก่อนเริ่ม

Today you build a paper model of a DNA double helix using a sequence you invent, then use the same sequence to practise base pairing, GC content and DNA length. Answers save in this browser, so use the same device for the whole session.

Part A · Origami DNA · แบบจำลองดีเอ็นเอกระดาษ

This activity comes from yourgenome.org (Wellcome Connecting Science). Follow the printed instructions; the steps below summarise them.

Steps

  1. Lay the blank template flat on the table.
  2. Invent a DNA sequence. Write its first base (A, C, G or T) in the top-right box, then continue down the right-hand column.
  3. In the boxes diagonally across from each base, write its partner: A with T, C with G.
  4. Colour every base using the pairing-rules sheet, so partners always share a colour pair.
  5. Fold the template into a double helix, following the activity guide or the video on the yourgenome page.
